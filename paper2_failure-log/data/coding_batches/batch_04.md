### 실수 163 — runQuery 「Internal server error」를 「조인·긴 IN 목록은 안 된다」로 오진 — 원인은 SQL 한 줄 255자 초과

2026-09-15 DEV-045 조사 중 [개발계-테스트] `runQuery`가 조인·EXISTS·긴 IN 목록에서 `Internal server error`(-32603)를 냈다. 「이 형태는 안 된다」로 보고 쿼리를 잘게 쪼개 라운드를 여러 번 더 썼고, 조인 대신 100행 상한 조회를 쓰다 기대값 오류(실수 162)까지 이어졌다. 실측: 똑같은 8개 IN 목록 쿼리가 **한 줄(259자)이면 실패, 줄바꿈으로 두 줄이면 성공**. 7개(246자)는 한 줄로도 성공. 이어 4개 테이블 조인 + EXISTS 서브쿼리 + DISTINCT도 줄을 나누니 그대로 동작했다.
