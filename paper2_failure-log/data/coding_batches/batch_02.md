DEV-015에서 확립된 코드수정 프로토콜(DEV카드→백업→수정본 선생성→[개발계-개발]→**CTS 이름검토**)에 명시돼 있고 그때는 후보 A/B를 제시해 사용자가 B를 골랐는데, 이후 2건에서 연속 생략. **실수 93 — 대시보드 패치를 heredoc으로 돌려 `task-board.html` JSON을 깨뜨렸다**

`inquiry-log.js`가 아닌 `task-board.html`의 `ailog` 갱신을 Bash heredoc(`python - <<'PY'`)으로 실행했다. 스크립트 안의 `\\n`(리터럴 백슬래시+n을 의도)이 **실제 줄바꿈으로 바뀌어** JSON 문자열이 998/999행으로 끊겼고, `const TASKS` 파싱이 통째로 실패했다. 그대로 뒀으면 **대시보드가 렌더링 자체를 못 했다.** 다행히 커밋 직후 JSON 검증을 돌려 즉시 발각.
→ **교훈: 이스케이프가 들어가는 스크립트는 heredoc으로 돌리지 말 것.** `Write` 툴로 `.py` 파일을 만든 뒤 `python 파일명`으로 실행한다. 8/20·8/21에 같은 작업을 `.py` 파일로 했을 땐 아무 문제가 없었다 — 방식만 바꿨다가 당했다.
