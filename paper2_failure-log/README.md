## 공개·비공개
- `data_private/`(원문·익명화 사전·후보 목록)은 **공개 금지**(.gitignore).
- `data/`는 익명화본과 메타만. 익명화 대상: 사람 이름(사전 57명), 회사·고객사·벤더(사전 33 + 규칙), 문서·전표·품의·문의·전송요청 번호, 사내 개발 오브젝트(Z 네임스페이스), 이메일·IP·전화. 개발계/운영계 구분은 실패의 핵심 정보라 역할 표기(「[개발계-테스트]」 「[운영계]」)로 남긴다.

## 알려진 한계·주의
- 1명·1조직 사례, 탐지 편향(드러난 실패만 기록).
- 날짜 근거가 섞여 있다: 세션 기록의 첫 작성 시각 131건 · 본문 날짜 51 · 제목 날짜 5 · 없음 1. 6/9 이전 항목은 세션 기록이 없어 주 모델을 모른다.
- 재번호 항목(「구 N」)은 옛 번호가 다른 항목과 겹쳐 세션 추적에서 제외했다.
- 180번은 제목이 「### 180.」 형식이라 초기 추출에서 179번에 붙어 있었다(분류자 A가 발견). 179번 분류는 두 분류자 모두 합쳐진 본문을 보고 했다 — 재분류 여부 판단 필요.
- `interventions.csv`의 겨냥 유형(target_codes)은 Claude 판단 — 저자 검토 필요.
